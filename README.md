# AQIQAT AI

Жасанды интеллект көмегімен жалған ақпаратты анықтауға көмектесетін веб-қосымша (Flask + SQLite + Three.js).

## Іске қосу

```bash
pip install -r requirements.txt
python app.py
```

Браузерде ашыңыз: http://localhost:5000 → «Тіркелу» арқылы аккаунт ашыңыз.

## Функциялар

| Бет | Не істейді |
|---|---|
| Басты бет | Мәлімдемені тексеру: мәтін белгілері + Wikipedia дереккөздері + AI пікірі |
| Дереккөзді тексеру | Сайттың тақырыбы, авторы, күні, домен жасы (RDAP), сенімділік белгілері |
| Сурет пен видео | Метадеректер (EXIF/XMP), өңдеу және AI генерация іздері, ELA картасы |
| Алаяқтықты анықтау | SMS/хаттағы алаяқтық белгілері, күмәнді сілтемелер, тәуекел деңгейі |
| Манипуляцияны анықтау | Эмоциялық қысым, қорқыту, жалпылау; бейтарап балама мәтін |
| Жеке деректер | Телефон, ЖСН, карта, құпиясөз, API кілтін табу және бүркемелеу |
| Шындықты анықта! | 24 тексерілген сұрақтан тұратын ойын: ұпай, деңгей, жетістіктер, рейтинг |

Барлық тексерулер пайдаланушының **тарихына** (SQLite: `instance/aqiqat.db`) сақталады.

## Vercel-де жариялау

1. **Тұрақты дерекқор (міндетті):** Vercel → жоба → **Storage** → **Create Database** → **Neon** (тегін) → жобаға қосыңыз. `DATABASE_URL` өзі қойылады. Онсыз аккаунттар мен тарих сақталмайды және пайдаланушы жүйеден шығып қалады.
2. **Тегін AI:** https://aistudio.google.com/apikey сайтынан Gemini кілтін алып, Vercel → Settings → Environment Variables бөліміне `GEMINI_API_KEY` ретінде қосыңыз.
3. **Redeploy** басыңыз.

## AI баптауы

`.env.example` файлын `.env` деп көшіріңіз.

- `GEMINI_API_KEY` (тегін) немесе `GROQ_API_KEY` (тегін) қойылса — модель тұжырым мен қазақша түсіндірме береді.
- `ANTHROPIC_API_KEY` қойылса — Claude моделі қолданылады.
- Кілт болмаса — жергілікті Ollama (`llama3.2:3b`) қолданылады. Шағын модель жиі қателесетіндіктен, оның пікірі тек кеңес ретінде көрсетіледі және қорытындыға әсер етпейді.
- AI мүлде болмаса да, сайт толық жұмыс істейді (белгілер мен дереккөздер негізінде).

## Қауіпсіздік

Құпиясөздер хэштеледі, барлық POST сұраулары CSRF белгісімен қорғалған, ішкі желі мекенжайларын жүктеуге тыйым салынған (SSRF), кіру әрекеттері шектелген, жүктелген файлдар дискке жазылмайды.
